# Statistical Mechanics — Lecture Notes

## Purpose

This folder contains study notes prepared to accompany selected lectures in a YouTube statistical mechanics lecture series. The notes are intended as a convenient reference for revision: they organize the main ideas, definitions, equations, and reasoning into a lecture-notes format.

## Sources and credit

The notes are based on the following original YouTube lectures:
[Course | Statistical Mechanics by Leonard Susskind at Stanford](https://www.youtube.com/playlist?list=PLpGHT1n4-mAsJ123W3fjPzvlDHOvIhHA0)

**Credit for note preparation:** ChatGPT (OpenAI) has been used to generate these notes from the linked lecture and the transcript provided. The notes have been updated here as generated. The notes may contain omissions or errors; compare them with the original source when accuracy matters.

## Mathematics rendering

The published site uses MkDocs Material with MathJax. For new or edited notes, use `\\(...\\)` for inline mathematics and `$$...$$` on separate lines for display mathematics. Some existing notes use `$$...$$` inline; those expressions should be checked when editing because the same delimiters are also used for display equations. This setup does not require changing the original Markdown merely to publish the site.
