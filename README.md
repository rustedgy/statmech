# Statistical Mechanics --- Lecture Notes

## Purpose

This repository contains study notes prepared to accompany selected lectures in a YouTube statistical mechanics lecture series. The notes are intended as a convenient reference for revision: they organize the main ideas, definitions, equations, and reasoning into a lecture-notes format.

## Sources and credit

The notes are based on the following original YouTube lectures:
[Course | Statistical Mechanics by Leonard Susskind at Stanford](https://www.youtube.com/playlist?list=PLpGHT1n4-mAsJ123W3fjPzvlDHOvIhHA0)


**Credit for note preparation:** ChatGPT (OpenAI) has been used to generate these notes from the linked lecture and the transcript provided. The notes have been updated here as generated. The notes may contain omissions or errors; compare them with the original source when accuracy matters.

## Formatting

Mathematical expressions in these Markdown files use dollar-sign delimiters (`$...$` for inline mathematics and `$$...$$` for display mathematics) for compatibility with common GitHub Markdown/MathJax workflows.

## Suggested use

-   Read the relevant lecture while consulting the notes.
-   Check equations and interpretations against the original lecture.
-   Treat the review questions as prompts for self-testing.
-   Open an issue or submit a correction if you find an error or unclear
    explanation.
