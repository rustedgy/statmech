# Statistical Mechanics — Lecture Notes (John Preskill)

## Purpose

This collection contains study notes accompanying selected lectures from John Preskill's Caltech Physics 12c (Statistical Mechanics) course. The notes organize the main ideas, definitions, equations, and reasoning into a convenient revision reference.

## Start here

- [Lecture 1 — Counting states](statistical_mechanics_lecture_1_notes.md) — microstates and macrostates, equal a priori probability, coin flips and spins, Stirling's approximation, and Gaussian fluctuations.
