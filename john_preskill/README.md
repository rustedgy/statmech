# Statistical Mechanics — Lecture Notes (John Preskill)

## Purpose

This folder contains study notes prepared to accompany lectures from John Preskill's Caltech Physics 12c (Statistical Mechanics) lecture series. The notes are intended as a convenient reference for revision: they organize the main ideas, definitions, equations, and reasoning into a lecture-notes format. They cover the physics only.

## Sources and credit

The notes are based on the following YouTube lectures:
[Physics 12c Statistical Mechanics (YouTube playlist)](https://www.youtube.com/playlist?list=PL0ojjrEqIyPzgJUUW76koGcSCy6OGtDRI)

**Credit for note preparation:** Claude (Anthropic) has been used to generate these notes. Where a lecture transcript was not available, the notes say which other source they were based on. The notes may contain omissions or errors; compare them with the original lecture when accuracy matters.

## Mathematics rendering

The published site uses MkDocs Material with MathJax. For new or edited notes, use `\\(...\\)` for inline mathematics and `$$...$$` on separate lines for display mathematics. Some existing notes use `$$...$$` inline; those expressions should be checked when editing because the same delimiters are also used for display equations. This setup does not require changing the original Markdown merely to publish the site.
